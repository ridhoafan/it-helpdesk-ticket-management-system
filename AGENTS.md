# Project Working Rules

1. Project menggunakan .NET 10, ASP.NET Core MVC, REST API, EF Core 10, SQL Server LocalDB, dan ASP.NET Core Identity.
2. Gunakan source code yang sudah ada sebagai sumber kebenaran. Selalu periksa implementasi aktual sebelum mengubah kode.
3. Pertahankan arsitektur MVC, REST API, Services, DTOs, Entities, dan Razor Views yang sudah ada.
4. Pertahankan authorization dan business rules untuk Admin, IT Support, dan Employee.
5. Jangan mengubah framework atau menambahkan dependency besar tanpa persetujuan.
6. Gunakan EF Core migrations untuk perubahan database. Jangan menjalankan migration atau database update tanpa persetujuan saya.
7. Jangan menghapus atau melemahkan validasi dan pemeriksaan authorization.
8. Jangan melakukan refactoring yang tidak berkaitan dengan pekerjaan yang sedang diminta.
9. Berkomunikasi dengan saya dalam Bahasa Indonesia.
10. Setelah perubahan, jalankan `dotnet build .\ITHelpdesk.slnx` jika relevan dan laporkan hasilnya.
11. Jangan melakukan commit, push, force-push, atau mengubah Git history tanpa persetujuan saya.
12. Jangan memasukkan password, token, database lokal, atau secret ke GitHub.
13. Kerjakan perubahan secara bertahap dan jelaskan setiap perubahan.
